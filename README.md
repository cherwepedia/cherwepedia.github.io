# Червепедия

Энциклопедия на Jekyll + GitHub Pages. Плагины не нужны: sitemap, RSS, поиск и пагинация сделаны своими средствами.

## Как добавлять статьи
Файл `_posts/ГГГГ-ММ-ДД-slug.md` с тем же front matter, что и раньше (`title`, `date`, `categories`, `intro`, `infobox`). Ничего менять не нужно.
Адрес статьи: `/категория/slug/`.

Необязательные поля: `aliases: [Другое название]` (для поиска), `last_modified_at: 2026-01-01`, `comments: false`, `telegram_post: 123`, `description:` (свой текст для сниппета).

## Картинки в тексте
```liquid
{% include card.html image="https://…/a.jpg" caption="Подпись" %}              {# справа от текста #}
{% include card.html image="…" caption="…" align="left" width="260" %}          {# слева, ширина 260px #}
{% include carousel.html images="a.jpg,b.jpg" captions="Подпись 1|Подпись 2" %} {# слайдер #}
{% include gallery.html images="a.jpg,b.jpg,c.jpg" captions="А|Б|В" columns="3" %} {# сетка на всю ширину #}
```
Подписи можно разделять запятой или `|`. Если в подписях есть запятые, а `|` не используется, запятые внутри подписи склеиваются автоматически (кусок со строчной буквы считается продолжением).

## Возраст в инфобоксе
Если в инфобоксе есть строка «Дата рождения» (форматы `15.03.1990`, `1990-03-15`, `15 марта 1990`, просто `1990`), к ней автоматически добавляется возраст, актуальный на сегодня. Если есть и «Дата смерти», возраст пишется у неё. Строка «Возраст» с датой рождения в значении заменяется на число лет.

## Рубрики
`_data/categories.yml` — названия и описания; скрытые по умолчанию — `hidden_categories` в `_config.yml` (сейчас «политика»).
Новая рубрика: допишите её в `categories.yml` и создайте `_cats/имя.md`:
```
---
category_id: новая
title: "Категория: Новая"
description: "Описание для поисковиков."
permalink: /новая/
---
```

## SEO — что сделать после выкладки
1. Google Search Console → «Файлы Sitemap» → удалить старый и добавить `https://cherwepedia.github.io/sitemap.xml`.
2. Яндекс Вебмастер → «Индексирование → Файлы Sitemap» → то же; проверить `robots.txt`.
3. Там же запросить переобход главной и нескольких статей.

## Локальный просмотр
- Jekyll: `bundle install && bundle exec jekyll serve` → http://localhost:4000
- Без Ruby (приближённо): `npm i && npm run preview:demo`
